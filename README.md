# 🛒 CodeAlpha E-Commerce Store

## Introduction

The **CodeAlpha E-Commerce Store** is a web-based shopping website developed using **Django and Bootstrap** as part of my **CodeAlpha Internship**.

The website allows users to **create an account, login, browse products, view product details, add products to the cart, and place orders**.

It also includes a **Django Admin Panel** where the admin can manage products, categories, users, and orders.

## Features

* User Registration and Login
* Product Listing
* Product Categories
* Product Details
* Add to Cart
* Update and Remove Cart Items
* Place Orders
* Django Admin Panel
* Responsive Design using Bootstrap

## Technologies Used

* Python
* Django
* HTML
* CSS
* Bootstrap
* SQLite

## Project Purpose

I created this project to learn how to build an **e-commerce website using Django** and understand how different parts like users, products, cart, and orders work together.

## How to Run

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open in browser:

```text
http://127.0.0.1:8000/
```

## Admin Panel

```text
http://127.0.0.1:8000/admin/
```

Create an admin account using:

```bash
python manage.py createsuperuser
```
